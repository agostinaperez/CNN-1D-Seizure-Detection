Detección automática de crisis epilépticas en señales EEG

Una red neuronal convolucional 1D (CNN-1D) clasifica ventanas de EEG como actividad ictal o basal y busca facilitar la revisión de registros prolongados.

Agostina Pérez · Instituto Universitario Aeronáutico · Docente: Gonzalez, Hernando Alexis

Ver código en GitHub Leer informe técnico (PDF)
01 · Problema y objetivo

¿Qué busca resolver?

La revisión visual de un monitoreo EEG continuo puede implicar muchas horas de señal y es una tarea demandante. El proyecto explora un sistema supervisado que analice registros pregrabados y señale ventanas que podrían corresponder a una crisis.

Entrada y salida

El sistema procesa archivos EEG en formato EDF. Para cada ventana genera una probabilidad de crisis; un umbral la convierte en una predicción de crisis o no crisis. Las ventanas se agrupan luego para evaluar episodios completos.

Uso previsto

Es un prototipo académico de apoyo a la decisión, no una herramienta diagnóstica ni un dispositivo clínico validado. La decisión final requiere revisión profesional.

02 · Datos

CHB-MIT Scalp EEG Database

Se trabaja con una base pública de EEG pediátrico continuo, anotada con intervalos de crisis. El conjunto crudo no se redistribuye en este repositorio; está disponible para investigación mediante PhysioNet.

Características utilizadas

  • Frecuencia de muestreo: 256 Hz.
  • 16 canales bipolares en un montaje canónico.
  • Ventanas de 5,12 s con 50 % de solapamiento.
  • Etiquetas derivadas de los tiempos de inicio y fin anotados.

Partición inter-paciente

La separación se realiza por paciente, no por ventana, para que registros de una misma persona no aparezcan a la vez en entrenamiento y evaluación. El test fijo queda apartado de las decisiones de entrenamiento.

03 · Metodología

Del registro a la evaluación

El procesamiento conserva el orden temporal de la señal y calcula las estadísticas de normalización únicamente con los datos de entrenamiento para reducir la fuga de información.

01 · PrepararSeleccionar y alinear los 16 canales.
02 · FiltrarPasa-banda de 0,5 a 50 Hz.
03 · VentanearVentanas de 5,12 s; solapamiento del 50 %.
04 · ClasificarCNN-1D estima probabilidad de crisis.
05 · EvaluarUmbral y métricas por ventana y por evento.

Modelo y entrenamiento

La arquitectura SeizureCNN apila seis bloques convolucionales 1D y una capa clasificadora. Se usa AdamW y se comparan BCE con peso para la clase positiva y Focal Loss, que ayudan a abordar el desbalance entre ventanas con y sin crisis.

Validación y selección

Se utiliza validación cruzada agrupada por paciente en cinco folds sobre el conjunto de desarrollo. La configuración se selecciona por la mediana de AUPRC (desempate por menor IQR); la ganadora se reentrena sobre todo el pool de desarrollo y se evalúa una sola vez sobre test con umbral fijo.

Métricas relevantes

  • Sensibilidad de evento
  • Falsas alarmas por hora
  • Latencia
  • AUPRC
  • AUC-ROC
  • Métricas por ventana

La sensibilidad de evento indica qué proporción de las crisis completas se detectó. AUPRC mide el equilibrio entre precisión y sensibilidad y es informativa cuando las clases están muy desbalanceadas. Las falsas alarmas por hora y la latencia complementan las métricas de clasificación con aspectos temporales de la detección.

05 · Discusión

Alcance y próximos pasos

Limitaciones observadas

  • La sensibilidad de evento del refit CV (55,9 %) queda por debajo del objetivo exploratorio de 90 %.
  • El refit CV respeta el techo de 1 falsa alarma/h (0,61), pero el modelo final previo (2,42/h) lo superaba: la elección del umbral fijo define el compromiso sensibilidad/alarmas.
  • Las crisis cortas son difíciles: en un paciente con eventos de aproximadamente 8 s, se detectaron 2 de 10.
  • La evaluación de test contiene 34 crisis; la diferencia entre configuraciones no permite afirmar una mejora concluyente.
